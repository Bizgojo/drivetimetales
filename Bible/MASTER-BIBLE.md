## 📰 NEWS BRIEFINGS SYSTEM

### Architecture
- **6 categories:** State, National, World, Business, Sports, Science & Tech
- **Cron job:** vercel.json at 0 11,17,23 UTC (6am/12pm/6pm ET)
- **Auto-generate toggle:** Stored in `news_settings` table, category='global'
- **Body audio:** Generated by Claude API + ElevenLabs TTS, starts with spoken date
- **No intro/outro baked into body audio**

### Playback Flow
| Page | Intro | Body | Outro |
|------|-------|------|-------|
| Welcome | Generic (pre-recorded) | News body | Generic (pre-recorded) |
| Home | Personalized (cached per user) | News body | Personalized (cached per user) |

### Personalized Intro/Outro
- 15 intro + 15 outro templates per category (120 total scripts)
- Audio generated for all 6 narrators, stored in `narrator_audio` table
- Personalized intros split into Part A (before name) + Part B (after name)
- First play generates and caches via ElevenLabs → `user_intro_cache` table
- Subsequent plays are instant from cache

- Warm, friendly, American female, no accent

## 🎙️ ADM (AUDIO DRAMA MAKER) — CURRENT STATE

### Version: 8.33.0 (February 9, 2026)

### Location
`~/DriveTimeFiles/ADM/Current/audio_drama_maker.py`

### Tabs (0-10)
| Tab | Name | Key Function |
|-----|------|-------------|
| 0 | Create | Story setup, API key, project creation |
| 1 | Import | Load script file |
| 2 | Edit | **Source of truth:** Title, Episode #, Episode Title. Auto-detects from script headers. |
| 3 | Voices | Character voice assignment. Series profiles auto-select from Tab 2 title. ANNOUNCER note points to Tab 6. |
| 4 | Generate | AI voice generation via ElevenLabs. Genre classification (primary + 3 sub-genres). |
| 5 | SFX | Sound effects management |
| 6 | Intro/Outro | **Announcer hub.** Voice (Belle, locked by default). Intro/outro text auto-populated from parsed ANNOUNCER lines. Generate audio. NEXT warns if audio not generated. |
| 7 | Music | Background music, Suno prompt integration |
| 8 | Mixing | Combine all tracks, REAPER export |
| 9 | Cover | AI cover art generation |
| 10 | Export/Publish | Publish to DTT. Series/episode info read-only (from Tab 2). Genre, duration, description. |

### Script Format
```
SERIES: Series Name Here
EPISODE: 1
EPISODE_TITLE: Episode Title Here
AUTHOR: Author Name
NARRATOR: Narrator Name
ANNOUNCER: Drive Time Tales

---

ANNOUNCER: Welcome to [series]...
NARRATOR: [narration]
CHARACTER: [dialogue]
[sound effect]
[PAUSE:2]
[BEAT]
```

### Workflow
```
Claude writes script with ANNOUNCER lines + metadata headers
→ Import to Tab 1
→ Parse on Tab 2 (auto-fills title, episode #, episode title; extracts ANNOUNCER → Tab 6)
→ Tab 3 auto-selects series profile, assign character voices
→ Tab 4 generate voice audio
→ Tab 5 add SFX (optional)
→ Tab 6 review/edit announcer scripts, generate announcer audio
→ Tab 7 select background music
→ Tab 8 mix (or export to REAPER)
→ Tab 9 generate cover art
→ Tab 10 publish to DTT
```

### Publish Confirmation
- v8.32.4 added confirmation dialog showing exact files being uploaded
- Matches audio/cover by story title first, then by most recently modified date
- **Known bug:** Can still upload wrong audio for narrator-only stories if Tab 5/8 skipped. Always verify files in confirmation dialog.

### Config File
`~/.audio_drama_maker_config.json` — stores default_announcer_voice, API keys, etc.
