## 2. Fail-closed routing chosen: PARK (not repair-loop) + why

On `qualityResult.error` (judge threw / API down / unparsable output):

- **Story:** `needs_attention=true` + reason (queryable, blocks re-dispatch until Marc clears via content-approval).
- **Job:** `status='failed'`, `current_step='quality_gate_tooling_error'` (new step value — greppable, distinct from `quality_gate_exhausted`), `error_json.kind='quality_gate_tooling_error'`, `gate='QUALITY-GATE-001'`, tooling error text preserved.
- **State marker:** `state_json.qualityGateToolingError={error, at}` — persistent, satisfies Lyra's Gap-2 micro-note (no silent path).
- **Response:** 422, shape mirrors the HOOK-GATE-001 failure (not the 200-halted exhausted shape — this is a blocking defect, not a clean stop).
- **Why park, not the rewrite loop:** the rewrite loop burns attempts rewriting a script the judge never scored — that destroys evidence and spends 3 Anthropic rewrites on an infra outage. Tooling errors are transient/infra; parking preserves content and resumes on next run after Marc clears. Repair-loop routing would be actively harmful here.

## 3. Runtime-check spec

- **Placement:** `complete_story_package` block, after `END HOOK-GATE-001`, before `STEP 10 QUALITY GATE`. Verified: HOOK end ~11513, quality `if (result.storyId)` ~11632 on branch.
- **Sources (verified live):**
  - Brief target: `stories.duration_mins` (numeric; set at `create_story_row` from queue `duration`, e.g. `'15 min'` → `15`) **preferred**; fallback parses `stories.brief_json.runtime` (same string shape), then `duration_label`. → `briefSecs = mins × 60`.
  - Actual: `state_json.renderFinalMix.durationSecs`, written by `runStandaloneRenderFinalMix` from the `runRenderFinalMix` report. **No ffprobe at gate time** — the gate runs on Vercel serverless where the build-time ffprobe binary (`/opt/homebrew/bin/ffprobe`, used only by offline `lib/assembleAndVerifyFinalMix.ts`) is absent.
- **Formula:** `deviation = (actual − brief) / brief`; pass iff `|deviation| ≤ 0.10`.
- **Thresholds:** one constants block in `lib/runtimeGate.ts` (`RUNTIME_GATE.TOLERANCE`, kinds). No magic numbers in route.
- **Fail routing (measured mismatch):** job `failed` / `current_step='runtime_gate_failed'` / `error_json.kind='runtime_brief_mismatch'` (per decision) with `actualSecs/briefSecs/deviationPct/tolerance` attached + story `needs_attention=true` park. **No autonomous repair** — a length mismatch needs editorial judgment (cut vs extend vs re-brief); auto-rewriting for length without a Marc spec risks content damage. 422 response.
- **Unmeasured inputs (either side null):** persistent skipped marker (`state_json.runtimeGate={status:'skipped', reason, at}` + mid-block `production_jobs` state/logs update + `console.warn`) and **continue**. Rationale: blocking on missing telemetry would strand in-flight jobs that rendered before `durationSecs` was recorded; mirrors the Lyra-accepted missing-scan-report pattern, upgraded with the required persistent marker.
- **ASSUMPTIONS (flagged):** (A1) `duration_mins` wins over `brief_json.runtime` on conflict. (A2) `renderFinalMix.durationSecs` is truthful (it comes from the render report, not re-probed at gate time — a corrupt report could pass the gate; post-mix re-verification is deferred per decision). (A3) ±10% applies uniformly across all brief lengths (10/15/20/25/30-min).
