# How to Create Your Google Form

This folder contains a Google Apps Script you can run to automatically build the form titled:

**Book Marketing Consultant Skills & Experience Form**

## Steps
1. Open **script.new** in your browser (or go to Google Drive → New → More → Google Apps Script).
2. Delete any sample code and paste the contents of `create_form.gs` into the editor.
3. Click **Save**, then **Run** → authorize the script when prompted.
4. The script will create the form in your Google Drive.  
5. Open **View → Logs** to copy the **Edit URL** and **Public URL** of your new Form.

### Notes
- The **file upload** question requires that respondents be signed into Google. In Google Workspace domains, you can restrict to your domain. On personal Google accounts, Forms will create a Drive folder to store uploads and may require sign-in.
- You can edit colors, header image, confirmation message, and response destination from the Form settings.
